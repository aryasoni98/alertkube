# alertkube site

Static landing page for [alertkube](https://github.com/aryasoni98/alertkube).

## Enable GitHub Pages

1. Repo → **Settings → Pages**
2. **Source**: Deploy from a branch
3. **Branch**: `master` · **Folder**: `/docs`
4. Save. Live at `https://aryasoni98.github.io/alertkube/` within ~1 min.

## Stack

- Single `index.html`
- Tailwind via CDN (no build)
- Inter + JetBrains Mono via Google Fonts

## Edit

Open `index.html`. Sections: hero, architecture, severity, watchers, pipeline, sinks, config, metrics, install, footer.
