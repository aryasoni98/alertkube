## Contributing

alertkube is Apache-2.0 licensed. By submitting a pull request you agree that your contribution is licensed under the same terms.

### Workflow

1. Open an issue at https://github.com/aryasoni98/alertkube/issues describing the change.
2. Fork, create a topic branch off `master`, and keep commits focused.
3. Run `go vet ./...`, `go test ./...`, and `helm lint helm/` before pushing.
4. Open a pull request referencing the issue.

### Legal

Contributions are accepted under the [Apache License 2.0](LICENSE-2.0.txt) via the [Developer Certificate of Origin](https://developercertificate.org/). Sign each commit with `git commit -s`.

For larger contributions where a CLA is required, contact the maintainer via a GitHub issue and the process will be coordinated there.
